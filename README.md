# Учебный проект: Мессенджер на Django

Это мой выпускной проект за 10 класс, представляющий собой веб-сайт со встроенным функционалом обмена сообщениями и элементами социальной сети. С этим проектом я выступил на научно-практической конференции "Шаг в будущее" XXXIII города Улан-Удэ и занял 3 место.

🛠 Используемые технологии:
- Бэкенд: Python, Django
- Фронтенд: HTML, CSS, JavaScript (Bootstrap, jQuery)
- Работа с данными: Django REST Framework

🚀 Основной функционал:
- Регистрация и авторизация пользователей.
- Отправка и получение личных сообщений.
- Просмотр ленты новостей/публикаций.
